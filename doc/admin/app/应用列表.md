
访问地址： `/admin/app/apk/list`
请求参数类型： `form-data` 
请求方式：`get`
接口输入：

#### 接口请求数据：

| 参数名称 | 类型 | 是否必选 | 备注     |
| :------- | :--- | :------: | :------- |
| `page`   | int  |    Y     | 显示几页 |
| `limit`  | int  |    Y     | 显示条数 |
 


#### 接口响应数据：

| 名称      | 类型   | 必选 | 说明        |
| --------- | ------ | ---- | ----------- |
| `code`    | string | 是   | 状态码      |
| `message` | string | 是   | 消息提示    |
| `data`    | json   | 是   | 详看 `data` |



`data数据：`

| 参数名称     | 参数类型 | 是否必选 | 说明                  |
| ------------ | -------- | -------- | --------------------- |
| `page`       | int      | Y        | 页码                  |
| `total_page` | int      | Y        | 分页数量              |
| `total`      | int      | Y        | 显示总条数            |
| `limit`      | string   | Y        | 显示条数              |
| `item`       | json     | Y        | 业务数据，详看 `item` |


`item数据：`

| 参数名称                | 参数类型  | 是否必选 | 说明                     |
| ----------------------- | --------- | -------- | ------------------------ |
| a_id                    | int       | 是       | id                       |
| a_status                | int       | 是       | 状态：0=正常,1=删除      |
| a_name                  | string    | 是       | 应用名称                 |
| a_package_name          | string    | 是       | APK包名                  |
| a_save_path             | string    | 是       | APK源包地址              |
| a_down_uri              | string    | 是       | APK下载链接后缀          |
| o_id                    | int       | 是       | OSS ID                   |
| o_name                  | int       | 是       | OSS 名字                 |
| a_domain                | array     | 否       | 301域名                  |
| down_link               | array     | 否       | 下载链接                 |
| a_replace_packager_name | int       | 是       | 包名替换：0=否，1=是     |
| a_is_compress           | int       | 是       | 是否压缩包：0=否，1=是   |
| a_enable                | int       | 是       | 自动打包开关             |
| a_limit                 | int       | 是       | 打包频率，格式：12:11:11 |
| a_last_package          | int       | 是       | 最后打包时间             |
| created_at              | timestamp | 否       | 添加时间                 |
| updated_at              | timestamp | 否       | 修改时间                 |



`错误编码数据：`

| 参数名称 | 说明         |
| -------- | ------------ |
| 000      | 成功         |
| 991      | 请先登录！   |
| 997      | 参数错误！   |
| 998      | 路由未定义！ |
| 999      | 系统异常！   |
