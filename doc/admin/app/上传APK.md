
访问地址： `/admin/app/apk/upload`
请求参数类型： `form-data` 
请求方式：`post`
接口输入：

#### 接口请求数据：

| 参数名称 | 类型 | 是否必选 | 备注                    |
| :------- | :--- | :------: | :---------------------- |
| file     | file |    是    | 文件，只能是apk后缀文件 |

 


#### 接口响应数据：

| 名称      | 类型   | 必选 | 说明        |
| --------- | ------ | ---- | ----------- |
| `code`    | string | 是   | 状态码      |
| `message` | string | 是   | 消息提示    |
| `data`    | json   | 是   | 详看 `data` |



`data数据：`

| 参数名称         | 参数类型 | 是否必选 | 说明                      |
| ---------------- | -------- | -------- | ------------------------- |
| `a_save_path`    | int      | Y        | APK链接，用于设置应用接口 |
| `a_package_name` | int      | Y        | APK包名，用于设置应用接口 |



`错误编码数据：`

| 参数名称 | 说明         |
| -------- | ------------ |
| 000      | 成功         |
| 991      | 请先登录！   |
| 997      | 参数错误！   |
| 998      | 路由未定义！ |
| 999      | 系统异常！   |
