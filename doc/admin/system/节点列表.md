
访问地址： `/admin/system/node/list`
请求参数类型： `form-data` 
请求方式：`get`
接口输入：

#### 接口请求数据：

| 参数名称 | 类型 | 是否必选 | 备注     |
| :------- | :--- | :------: | :------- |
| `page`   | int  |    Y     | 显示几页 |
| `limit`  | int  |    Y     | 显示条数 |
 


#### 接口响应数据：

| 名称      | 类型   | 必选 | 说明        |
| --------- | ------ | ---- | ----------- |
| `code`    | string | 是   | 状态码      |
| `message` | string | 是   | 消息提示    |
| `data`    | json   | 是   | 详看 `data` |



`data数据：`

| 参数名称     | 参数类型 | 是否必选 | 说明                  |
| ------------ | -------- | -------- | --------------------- |
| `page`       | int      | Y        | 页码                  |
| `total_page` | int      | Y        | 分页数量              |
| `total`      | int      | Y        | 显示总条数            |
| `limit`      | string   | Y        | 显示条数              |
| `item`       | json     | Y        | 业务数据，详看 `item` |


`item数据：`

| 参数名称       | 参数类型 | 是否必选 | 说明                 |
| -------------- | -------- | -------- | -------------------- |
| `an_id`        | int      | Y        | 节点ID               |
| `an_pid`       | int      | Y        | 节点父级ID           |
| `an_name`      | string   | Y        | 权限节点名称         |
| `an_code`      | string   | Y        | 节点路由             |
| `an_is_dir`    | int      | Y        | 是否为目录,0=否,1=是 |
| `an_is_hidden` | int      | Y        | 是否隐藏,0=否,1=是   |
| `created_at`   | string   | Y        | 创建时间             |
| `updated_at`   | string   | Y        | 更新时间             |



`错误编码数据：`

| 参数名称 | 说明         |
| -------- | ------------ |
| 000      | 成功         |
| 991      | 请先登录！   |
| 997      | 参数错误！   |
| 998      | 路由未定义！ |
| 999      | 系统异常！   |
