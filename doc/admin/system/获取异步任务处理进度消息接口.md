
访问地址： `/admin/system/msg/task/list`
请求参数类型： `form-data` 
请求方式：`get`
接口输入：

#### 接口请求数据：

| 参数名称 | 类型 | 是否必选 | 备注       |
| :------- | :--- | :------: | :--------- |
| `msg_id` | int  |    Y     | 任务消息ID |
 


#### 接口响应数据：

| 名称      | 类型   | 必选 | 说明        |
| --------- | ------ | ---- | ----------- |
| `code`    | string | 是   | 状态码      |
| `message` | string | 是   | 消息提示    |
| `data`    | json   | 是   | 详看 `data` |



`data数据：`

| 参数名称 | 参数类型 | 是否必选 | 说明                                                                                       |
| -------- | -------- | -------- | ------------------------------------------------------------------------------------------ |
| `status` | int      | Y        | 状态：0=开始，1=进行中的消息，2=结束(需要停止获取消息)，98=警告，99=异常(需要停止获取消息) |
| `msg`    | string   | Y        | 进度描述                                                                                   |





`错误编码数据：`

| 参数名称 | 说明         |
| -------- | ------------ |
| 000      | 成功         |
| 991      | 请先登录！   |
| 997      | 参数错误！   |
| 998      | 路由未定义！ |
| 999      | 系统异常！   |
