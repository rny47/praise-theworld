
访问地址： `/admin/system/config/save`
请求参数类型： `form-data` 
请求方式：`post`
接口输入：

#### 接口请求数据：

| 参数名称         | 类型 | 是否必选 | 备注     |
| :--------------- | :--- | :------: | :------- |
| `ac_code`        | int  |    Y     | 配置编码 |
| `ac_val`         | int  |    Y     | 配置值   |
| `ac_description` | int  |    Y     | 配置备注 |
| `ac_id`          | int  |    Y     | ID       |
 

#### 接口响应数据：

| 名称      | 类型   | 必选 | 说明        |
| --------- | ------ | ---- | ----------- |
| `code`    | string | 是   | 状态码      |
| `message` | string | 是   | 消息提示    |
| `data`    | json   | 是   | 详看 `data` |


`错误编码数据：`

| 参数名称 | 说明         |
| -------- | ------------ |
| 000      | 成功         |
| 991      | 请先登录！   |
| 997      | 参数错误！   |
| 998      | 路由未定义！ |
| 999      | 系统异常！   |
