
访问地址： `/admin/system/node/save`
请求参数类型： `form-data` 
请求方式：`post`
接口输入：

#### 接口请求数据：

| 参数名称       | 类型   | 是否必选 | 备注                 |
| :------------- | :----- | :------: | :------------------- |
| `an_id`        | int    |    Y     | 节点id               |
| `an_name`      | string |    Y     | 节点名称             |
| `an_code`      | string |    N     | 节点地址             |
| `an_pid`       | int    |    Y     | 节点父级ID           |
| `an_is_dir`    | int    |    Y     | 是否为目录,0=否,1=是 |
| `an_is_hidden` | int    |    Y     | 是否为隐藏,0=否,1=是 |



#### 接口响应数据：

| 名称      | 类型   | 必选 | 说明        |
| --------- | ------ | ---- | ----------- |
| `code`    | string | 是   | 状态码      |
| `message` | string | 是   | 消息提示    |
| `data`    | json   | 是   | 详看 `data` |


`错误编码数据：`

| 参数名称 | 说明         |
| -------- | ------------ |
| 000      | 成功         |
| 991      | 请先登录！   |
| 997      | 参数错误！   |
| 998      | 路由未定义！ |
| 999      | 系统异常！   |
