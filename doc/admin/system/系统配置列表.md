
访问地址： `/admin/system/config/list`
请求参数类型： `form-data` 
请求方式：`get`
接口输入：

#### 接口请求数据：

| 参数名称 | 类型 | 是否必选 | 备注     |
| :------- | :--- | :------: | :------- |
| `page`   | int  |    Y     | 显示几页 |
| `limit`  | int  |    Y     | 显示条数 |
 

#### 接口响应数据：

| 参数名称  | 参数类型 | 是否必选 | 说明                   |
| --------- | -------- | -------- | ---------------------- |
| `code`    | int      | Y        | 状态，详见以下错误编码 |
| `message` | string   | Y        | 提示错误信息或成功信息 |
| `data`    | json     | Y        | 详见以下响应data数据   |

`data数据：`

| 参数名称     | 参数类型 | 是否必选 | 说明                  |
| ------------ | -------- | -------- | --------------------- |
| `page`       | int      | Y        | 页码                  |
| `total_page` | int      | Y        | 分页数量              |
| `total`      | int      | Y        | 显示总条数            |
| `limit`      | string   | Y        | 显示条数              |
| `item`       | json     | Y        | 业务数据，详看 `item` |


`item数据：`

| 参数名称         | 参数类型 | 是否必选 | 说明     |
| ---------------- | -------- | -------- | -------- |
| `ac_id`          | int      | Y        | id       |
| `ac_code`        | string   | Y        | 配置编码 |
| `ac_val`         | string   | Y        | 配置值   |
| `ac_description` | string   | Y        | 配置备注 |
| `created_at`     | string   | Y        | 更新时间 |
| `updated_at`     | string   | Y        | 更新时间 |



`错误编码数据：`

| 参数名称 | 说明             |
| -------- | ---------------- |
| 000      | 成功             |
| 995      | 请先登录！       |
| 997      | 保留错误码！     |
| 998      | 请求对象未定义！ |
| 999      | 系统异常！       |
