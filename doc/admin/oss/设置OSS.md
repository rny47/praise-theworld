
访问地址： `/admin/storage/oss/save`
请求参数类型： `form-data` 
请求方式：`post`
接口输入：

#### 接口请求数据：

| 参数名称       | 类型   | 是否必选 | 备注                                                                  |
| :------------- | :----- | :------: | :-------------------------------------------------------------------- |
| `o_id`         | int    |    否    | id，有则修改，无则新增                                                |
| `o_name`       | string |    是    | OSS名字                                                               |
| `o_quicken`    | int    |    是    | 开启加速：0=不开启,1=开启                                             |
| `o_type`       | string |    是    | 类型：tencent=腾讯,s3=亚马逊,minio=MinIO                              |
| `o_host`       | string |    否    | 存储云地址，只有在类型为MinIO的时候，该参数必填，其他类型掩藏无需传递 |
| `o_key_id`     | string |    是    | KeyId                                                                 |
| `o_key_secret` | string |    是    | KeySecret                                                             |
| `o_app_id`     | string |    是    | 桶应用ID ，选择腾讯云时必须传，选择亚马逊云，不需要该参数             |
| `o_region`     | string |    是    | 区域     ,按照枚举值选择，如：ap-hongkong                             |

`o_region` 区域枚举值,在选择类型是腾讯云的时候，可选择以下值：

| 参数名称     | 说明     |
| ------------ | -------- |
| ap-hongkong  | 中国香港 |
| ap-singapore | 新加坡   |
| ap-seoul     | 首尔     |
| ap-bangkok   | 曼谷     |
| ap-tokyo     | 东京     |

`o_region` 区域枚举值,在选择类型是亚马逊云的时候，可选择以下值：

| 参数名称       | 说明   |
| -------------- | ------ |
| ap-northeast-3 | 大阪   |
| ap-northeast-2 | 首尔   |
| ap-southeast-1 | 新加坡 |
| ap-northeast-1 | 东京   |
| ap-east-1      | 香港   |

| 名称      | 类型   | 必选 | 说明        |
| --------- | ------ | ---- | ----------- |
| `code`    | string | 是   | 状态码      |
| `message` | string | 是   | 消息提示    |
| `data`    | json   | 是   | 详看 `data` |
